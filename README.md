# Smart Restaurant Management System

A contactless restaurant ordering system built with Flask. Customers scan a QR code or tap an NFC tag at their table to view the menu and place orders, with no app and no waiting for a waiter.

## Features
- QR / NFC table-side ordering
- Menu browsing and order placement
- Staff view to manage incoming orders

## Tech Stack
- Python, Flask
- HTML, CSS, JavaScript
- SQLite (change this if you use another database)

## How to Run
1. Clone the repo:
   `git clone https://github.com/ridhavp10-hash/menuapp.git`
2. Go to the folder:
   `cd menuapp`
3. Install requirements:
   `pip install -r requirements.txt`
4. Start the app:
   `python app.py`
5. Open `http://127.0.0.1:5000` in your browser.
